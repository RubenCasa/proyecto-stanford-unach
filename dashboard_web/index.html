De dónde sale cada número

Todo se calcula con scripts de R reproducibles (01 a 13) que están en el repositorio del proyecto.

  1. Se unifican los archivos del ECU 911 y se limpian (fechas, duplicados, parroquias).
  2. Se filtra Riobamba y se clasifica cada registro con el catálogo COIP.
  3. Se predice solo el código 1 (delito explícito) por parroquia y semana.
  4. Zona urbana: random forest. Parroquias rurales: binomial negativa.
  5. La tendencia a 2029 usa el método que mejor acertó en un backtest de 24 meses.

Limitaciones

  • El ECU 911 registra llamadas, no sentencias: lesiones, tránsito y drogas dependen de datos que solo tiene la Fiscalía.
  • Flores y Cubijíes tienen pocos casos: 91 % y 64 % de sus semanas no tienen ninguno. Se pronostica una probabilidad, no un número exacto.
  • Febrero de 2023 no trae subtipo y se estimó con los meses vecinos.
  • La base de la Fiscalía se incorporará para validar el modelo.
